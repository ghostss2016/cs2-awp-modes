# AWP Modes implementation scope

This repository is the AWP-focused branch of the native MetaMod arena engine.
The first release deliberately exposes only AWP rounds by default. Optional Scout,
Deagle and Knife rounds are controlled by `AWPMode` in the server config.

The old generic K4 feature comparison was removed from this repository because it
described a wider, non-AWP catalogue and was misleading for this server.
